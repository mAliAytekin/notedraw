# tldraw UI translations

Official tldraw 5.5.2 assets from https://cdn.tldraw.com/5.5.2/translations/tr.json
and https://cdn.tldraw.com/5.5.2/translations/en.json, retrieved 2026-10-09.
English defaults are built into the SDK; its en.json is intentionally `{}`.
These files are supplied under the same terms as the tldraw SDK.
Update them with tldraw upgrades. They are served locally so changing the
application's language does not depend on a translation CDN request.
Two keys missing from the official Turkish asset have been completed locally:
`shortcuts-dialog.disabled-notice` and `comments.link-copied`.
